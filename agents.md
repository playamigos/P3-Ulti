# Agent Instructions

**To any AI Agent reading this repository:**

This `docs/` directory contains the source of truth for the project state. You MUST read and update these files in real-time as the project evolves, the app goes through changes, or the user provides new requirements.

- `roadmap.md`: Update this when phases are completed or when new long-term goals are added. Mark tasks as done (`[x]`).
- `implemented.md`: Add detailed notes about features as soon as they are fully implemented and working.
- `user_requirements.md`: Append or modify requirements immediately when the user specifies new constraints or desires.
- `techstack.md`: Keep this updated with the exact libraries, frameworks, and APIs used in the codebase.
