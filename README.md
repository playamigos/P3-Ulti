# Ulti: Focused Text Viewer

Ulti is an innovative text-rendering application designed to improve reading focus and reduce visual fatigue. Similar to a PDF viewer but with a unique twist: it enhances the reading experience by automatically keeping the user's focus on the current line.

## Core Concept
The primary feature of this application is its dynamic text visibility powered by intelligent tracking. Unlike manual reading rulers, Ulti aims to use a combination of **camera (eye and head movement tracking)** and **voice recognition** to accurately track the user's current reading placement. It dynamically enlarges and enhances the visibility of the exact line being read, while subtly dimming the rest of the text. This creates a seamless, hands-free reading experience that prevents losing one's place, even in large paragraphs with tiny text.

## Roadmap
- **Phase 1:** Build a simple text viewer with preloaded text.
- **Phase 2:** Implement the dynamic focus/dimming visual feature.
- **Phase 3:** Integrate camera-based head/eye tracking and voice-based position syncing.
- **Phase 4:** Add support for various file extensions (e.g., .txt, .pdf, .epub).
