# User Requirements

- The application must be a text rendering app that improves reading focus.
- **Dynamic Text Visibility:** Enhance and enlarge the visibility of the exact line the user is reading. Reduce visibility (dim) of the rest of the text.
- **Intelligent Predictive Autopilot:** A microphone-based feedback loop that syncs the text magnifier to the user's spoken voice and calibrates the visual scrolling WPM.
- **"Speak Out" Text-to-Speech Player:** An automated audio reader option using premium system voices that visually highlights words in perfect synchronization with the spoken audio boundaries. Calibrates speaking speed rate directly from WPM adjustments and pauses/resumes in response to reader play/pause inputs.
- **Preloaded Library & Progress Tracking:** A landing Library Dashboard containing a list of preloaded educational book modules divided into chapters. The dashboard displays the reading progress (percent read and active chapter index) for each book.
- **Handling Complex Text:** The solution must be robust enough to handle large paragraphs and tiny text effectively.
- **Mobile Responsiveness:** The UI must be fully responsive, scaling layout dimensions and collapsing labels to icons on small viewports while preserving complete formatting control and autopilot behaviors.
